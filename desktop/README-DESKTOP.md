# KothaFlow Desktop Voice Typing (উইন্ডোজ ও ম্যাক গাইড)

KothaFlow ডেস্কটপ অ্যাপে এখন যুক্ত হয়েছে **Wispr Flow স্টাইল ভাসমান ভয়েস বাবল (Floating Bubble)** এবং গ্লোবাল হটকি। এর মাধ্যমে আপনি কম্পিউটারের যে কোনো সফটওয়্যারে (MS Word, Notepad, VS Code, Google Chrome, WhatsApp Desktop, Messenger, Notion, ইত্যাদি) সরাসরি মাউসের কার্সারে মুখে বলে টাইপ করতে পারবেন।

## কম্পিউটার চালানোর নিয়ম:
1. **উইন্ডোজের জন্য:** শুধুমাত্র `run-windows.bat` ফাইলটিতে ডাবল ক্লিক করুন।
2. **ম্যাক/লিনাক্সের জন্য:** টার্মিনালে `./run-mac-linux.sh` ফাইলটি চালান।
3. প্রথমবার চালু করলে স্বয়ংক্রিয়ভাবে স্ক্রিনের নিচে-ডানে **KothaFlow ভাসমান বাবল** দেখা যাবে।

## ব্যবহারের নিয়ম:
1. **পদ্ধতি ১ (ভাসমান বাবল):** স্ক্রিনে থাকা KothaFlow বাবলে মাউস দিয়ে ক্লিক করুন। এটি সুন্দর রেকর্ডিং বারে রূপান্তরিত হবে। কথা শেষ হলে টিকচিহ্ন বাটনে চাপুন — স্বয়ংক্রিয়ভাবে লেখার স্থানে টাইপ হয়ে যাবে!
2. **পদ্ধতি ২ (কিবোর্ড শর্টকাট):** যেকোনো অ্যাপে কার্সার রেখে কীবোর্ডে **`Ctrl + Shift + Space`** চাপুন (ম্যাকে `Command + Shift + Space`)। কথা বলে আবার শর্টকাট চাপুন।
3. **বাবল ড্র্যাগিং:** বাবলটিকে মাউস দিয়ে টেনে স্ক্রিনের যেকোনো জায়গায় সরিয়ে রাখতে পারবেন।
4. **ভাষা পরিবর্তন:** বাবলের ওপর মাউসের রাইট-ক্লিক করে বাংলা অথবা ইংরেজি ভাষা সিলেক্ট করতে পারবেন।
